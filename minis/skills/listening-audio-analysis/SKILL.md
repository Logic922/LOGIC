# 听力文本分析

把试卷听力音频转成中英对照文本，再结合试卷照片定位每题依据、生成错题分析。

## 一、必读前提（Apple Speech 实测行为）

单语言模型，**不支持语种切换**，这是全部坑的根源：

1. **en-US 模型遇到中文 → 输出乱码英文**（`Just shitting guy lady`、`Shawty`、`show me the lion R T`）。
   这些**不是幻觉、不是噪声，而是真实的中文播音**被英文声学模型硬转。**千万不要当噪声删掉**——它们就是音频里的"听下面的录音，回答第 X 小题"。
2. **zh-CN 模型遇到英文 → 输出乱码英文**（`fucking find of now`、`Intouchable`）。
3. **绝对不要用 `auto`**：它按设备语言锁定。中文设备上，哪怕切出一段纯英文，也照样返回 `zh_CN` 并给出乱码。
   → **必须显式指定 `--language`，两种语言各跑一遍。**
4. **整段长音频调用不可靠**：17 分钟音频可能耗时 300s，也可能**返回空文本而不报错**。必须校验 `data.text` / `segments` 非空并重试。
5. **整段调用的 `timestamp` 全为 0**；**分块调用（≲2 分钟）会返回真实 `timestamp` 和 `confidence`**。
   → 所以必须分块：分块是拿到时间戳、从而自动对齐两种模型的唯一途径。
6. **成本模型**：每次调用约 7 秒固定开销，总耗时 ≈ 调用次数 × 7s。
   → 块太少会中英混在同一块里无法分类；块太多太慢。默认每块约 100 秒。
7. **本环境 ffmpeg 必须显式加 `-loglevel info`**，否则 stderr 被丢弃（`silencedetect` 会返回 0 个静音点，且重定向到文件也是 0 字节）。

## 二、工作流

### 第 1 步：转写（用脚本，别手搓）

```bash
python3 /var/minis/skills/listening-audio-analysis/scripts/listen2text.py <audio> <out.md> \
        [--target 100] [--gap 2.0] [--keep-dup]
```

脚本做的事：ffmpeg 静音切分 → 每块分别跑 zh-CN / en-US → 按时间戳把"与中文段重叠的英文段"判为中文并换成中文原文 → 自动去掉"读两遍"的重复。

17 分钟音频约 **4 分钟**跑完。**必须放后台**，不要干等：

```bash
setsid nohup python3 .../listen2text.py <audio> <out.md> > /root/l2t.log 2>&1 < /dev/null &
```

然后用 shell_execute 的 `delay` 轮询 `cat /root/l2t.log`（每 60–90 秒一次），看到"完成："即结束。

### 第 2 步：润色（必做，不可省）

脚本输出是**毛坯**，块边界必有瑕疵，逐条修：

| 瑕疵 | 例子 | 处理 |
|---|---|---|
| 块尾单词被切断 | `...learn a lot from these ea` + 下段开头 `rly techniques` | 把相邻段落首尾接回去 |
| 中文指令被切碎 | `听下面的录音` / `的录音回答第X至第Y小题` | 合并为一条完整指令 |
| 中文模型往英文区插字 | `听下面的录音回答第三小题哈喽` | 删掉多余中文 |
| 中文指令里的数字丢失 | `第至第小题现在你有秒钟` | 按卷面题号补（阅读时间 = 小题数 × 5 秒） |
| 专有名词/数字听错 | `Lee Lynn`、`brought in their horizons`、`4 5 %` | 按上下文校正为 Li Lin、broaden、4.5% |

**说话人标记**：能判断的按题面判断（`sir`/`madam`、`Mr. Young`/`Rose`、`Mom`）；**不能判断的用 A/B 表示问答顺序，不要硬猜男女**——猜错会污染后续分析。

### 第 3 步：与试卷对应

1. 试卷照片先**旋正 + 按页裁剪 + 放大 2–3 倍**（PIL `crop` + `resize(LANCZOS)`）再读，题目小字才看得清；
2. 用音频里中文指令的"回答第 X 至第 Y 小题"把**材料 ↔ 题号**绑定；
3. **红笔 = 老师的批改**：红笔写的就是正确答案，红笔划掉的学生答案即错题；**没有红笔的题视为做对**。

### 第 4 步：产出分析

每题给：**你的答案 / 正确答案 / 原文依据（逐句引文）/ 错因分析 / 方法提示**。
最后按题型汇总失分、给出提分优先级。听力题尤其要点明陷阱类型：时间推算、预期 vs 现实、已做 vs 计划做、结尾总结句。

需要出 PDF → 用 **`chinese-pdf-report`** 技能（中文排版与字体另有专门的坑）。

## 三、交付前自查

- **分数自洽**：按红笔统计的失分应等于卷面扣分（对不上 = 漏题或重复计）；
- **数量自洽**：听力题数 = 材料数 × 每题小题数；
- **覆盖完整**：脚本日志里各块的时间区间应**首尾相接且覆盖到音频末尾**（例如 `0-110s`、`110-236s`……）。若中间蹦出 `236-236s` 这种零长块，或总覆盖明显小于音频时长，就是切分/合并出错了——修脚本而不是硬凑。
- **痕迹自查**：中文指令数应 ≈ 材料数 + 2（开场 + 分节），少太多说明 zh 模型有块返回空，需重跑该块。

## 四、常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 脚本报告 `0 cuts` | ffmpeg 缺 `-loglevel info` | 用本 skill 的脚本（已内置），别自己拼命令 |
| 某块 `zh=0 segs` | 整块/超长音频调用偶发返回空 | 脚本已自动重试 2 次；仍为 0 就减小 `--target` 重跑 |
| 整份输出全是英文乱码 | zh 模型全部失败 | 检查是否把 `--language` 漏掉了 |
| 输出里出现 `Shawty`/`shit` 等 | 某段中文没被时间戳对齐拦下 | 手工替换为该位置对应的中文指令 |
