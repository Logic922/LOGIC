# 教学模拟（teaching simulations）

用单文件 HTML / 纯前端做的高中物理、化学课堂演示与动画，双击即可在浏览器打开，无需构建、无需联网。

```
教学模拟/
├── CO2制甲醇演示/            化学反应速率与分流机制演示（2 页）
├── 凹槽传送带动画/           凹槽A · 滑块B · 传送带C 运动模拟（html + css + js）
├── 圆环三球/                 三球圆环问题：运动动画 + 第(3)问的优雅解法
├── 波沙盒/                   波的干涉 / 衍射 3D 沙盒（Three.js，含引擎单测）
├── 圆环碰撞.html             三球圆环 · 运动动画（单文件版）
├── 摆的沙盒.html             动铰摆 / 单摆沙盒
└── 斜面圆弧动铰摆.html       斜面·圆弧·动铰摆 动画
```

| 条目 | 知识点 | 形态 |
|---|---|---|
| CO2制甲醇演示 | CO₂ 加氢制甲醇的分流机制与速率 | 双页 HTML |
| 凹槽传送带动画 | 相对运动 / 传送带模型 | 模块化 HTML+CSS+JS |
| 圆环三球 | 圆周运动、约束与能量 | 动画 + 解法页 |
| 波沙盒 | 波的干涉、衍射（惠更斯） | Three.js 3D 沙盒 |
| 圆环碰撞.html | 同上，单文件版 | 单文件 HTML |
| 摆的沙盒.html | 单摆 / 动铰摆 | 单文件 HTML |
| 斜面圆弧动铰摆.html | 斜面 + 圆弧 + 动铰摆复合运动 | 单文件 HTML |

打开方式：直接浏览器打开 `index.html`（或对应 html）；`波沙盒` 的 `three.min.js` 为本地依赖，必须连同目录一起移动。
